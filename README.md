# THE STARS THAT SANK US TO SLEEP - Part 1: Lullaby

A story-first 2D stealth and physics escape game, playable in the browser.

Team Evangelion - TGC Game Jam 2026 (Infinium26, IIIT-H).

## Team

- Panem Chaitanya Pavan Kumar
- Prakash Bhabad
- Metta Venkata Ramana Murthy

## The game

- **Genre:** narrative stealth and physics puzzle, 2D side-view
- **Engine:** Godot 4 (GDScript)
- **Platform:** HTML5 export on itch.io, for desktop browsers
- **Controls:** keyboard - move, interact, and Tab to switch between the kids

## Scope

Part 1 is a single 15-20 minute playthrough covering Acts 1-3 and the finale.

Part 2 and later are planned: the world outside the farm belongs to them.

## Development

All code was written inside the 100-hour jam window.
